# 0039. Paper cites a renamed later version as published, confirms every lit-review entry in the session, and chains from the works closest to each gap

Status: proposed; superseded by 0040 in its sentence on a `bibtex --page` refusal, since the strategist no longer runs `bibtex --page`, and in its third item, the gap chaining; superseded by the ruling The academic-paper strategist of plan 5 in full

## Context

The lit-review comparison of `paper` on `v8.4.0-rc.8` against two runs of academic-paper 3.2.0 on the same request held three points against `paper` that its text caused (`.scratch/5-paper/agents/reviews/5.G-check-blind-comparison.md`, "What the judges held against `paper`"):

- The core of one research community in the request was missing: Kundu's transport-based morphometry and Gong's CMOT-Fusion. Judge 2. The run found one transport-based morphometry paper, `Shifat_E_Rabbi_2025a`, as a supporting source, and no work by Kundu.
- The TMLR version of Thual et al. was kept as a preprint after a title ratio of 0.42. Judges 1 and 4.
- The confirmation of every one of the 225 entries rested on the merge run's report, and no run of the session's own checked it. Judge 4. The run's final message said that every entry printing `CONFIRMED` under `resolve --entry` was not checked by the session.

## Decision

Each item below is a deviation from academic-paper 3.2.0.

- The strategist also looks for a later version of a preprint under another title: a work that forward tracking, a title search or a venue an index names brings up, with the preprint's first author, a year at or after the preprint's, and a title or abstract that states the same contribution. A later version that an index links to the preprint keeps the route "Preprints and published versions" gives. A later version that no index links to the preprint is a source of its own: it is included when `lookup.py resolve '<its title>' --year <year>` prints a record that matches it, its entry is written from that record as ADR 0032 decides for a source with neither a DOI nor an arXiv ID, `resolve --entry` confirms it, and its annotation's Type names the preprint by its arXiv ID as its earlier version. The preprint gets no entry unless the run cites a passage only the preprint holds, and then each annotation names the other. A `bibtex --page` refusal for a title ratio below 0.70 sends the agent to this search before the `@misc` entry stays. `lookup.py` does not change. Reason: the published work is cited, as a reader of the review expects.
- In lit-review mode the session runs `lookup.py resolve --entry` on every key of `refs.bib` itself, after the sources' review and before any patch is applied, and writes each run into `checks.md`. An entry it does not confirm goes to the strategist once (the merge run's strategist after theme runs) with the line printed, and is corrected or taken out of `refs.bib`, the synthesis and the patch. The session runs `resolve --entry` again on each corrected entry, and an entry still not confirmed is taken out. It then checks that every key the synthesis cites stands in `refs.bib`. The final message states the count of entries the session's runs confirmed, out of the entries `refs.bib` holds, and names each entry taken out. Reason: the confirmation the review states rests on a run the session made, and the patch carries only confirmed entries.
- Before a gap is written, and for each part with fewer included sources than the smallest count among the other parts, the strategist chains backward from at most 3 of the works that come closest to it and screens what they cite as layer 2's candidates are screened. This gap chaining runs once, after the passes have ended, and is no pass: it does not count toward the cap of 8 passes, does not test the end conditions again, and its seeds are not core papers. A work it finds that closes the gap is included, read and annotated, and the gap is then not written or written narrower. A theme run keeps such a work past the upper bound of its range, since the gap's evidence rests on it. The search record names each gap chaining with its gap or part, its seed keys, the count of works screened and the keys added. A theme run runs it for its own gaps and thin parts, and the merge run for the gaps it writes over the whole set and the thin parts of the merged set, which adds the gap chaining to the merge run's own searches of ADR 0037. Reason: the core of a field that the set misses is searched for where the gaps show it.

## Alternatives rejected

- Chaining from every included source: in a run of 225 sources, chaining from each source screens about 9,000 candidates in place of about 400 from at most 3 seeds per gap or thin part, so the cost grows with the set while the works that matter for a missing core are the ones next to the gap.
- Keeping the preprint when the later version has another title: the published work stays uncited, which the judges held against the rc.8 run, and a reader of the review takes the preprint for the latest form of the work.
- A `bibtex --page` form that checks a venue page against an index record found by the page's title: it contradicts ADR 0032, which writes the entry of a source with neither identifier from the record `resolve` prints, and it adds a script form for what that record already gives.

## Consequences

- A lit-review run cites a renamed later version with the venue and year its index record names, and its annotation names the preprint, so a reader can find both.
- A lit-review run makes one `resolve --entry` call per entry of `refs.bib` in the session. `lookup.py` caches each reply, so a second run over the same entries within the cache's life asks no index again. An entry the strategist cannot correct is taken out and named in the final message.
- Each search makes one more round of backward chaining after its passes, bounded by 3 seeds per gap or thin part, and its search record grows by one line per gap chaining.
- `skills/academic/paper/SKILL.md` (lit-review item 3, Steps 8, the Agent prompts table and the sentence on the commands the session runs), `skills/academic/paper/agents/literature_strategist_agent.md`, the `paper` skill's `references/literature-strategist-theme-run.md`, the `paper` skill's `references/literature-strategist-merge-run.md`, `docs/academic-coverage.md`, `docs/glossary.md`, `README.md` and the figures carry these decisions.
