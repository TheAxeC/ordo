# 0025. A paper run is done by six agent roles, three of them resumed for a second message in named cases, and the integrity and ethics checks belong to researcher

Status: superseded by 0027

## Context

ADR 0022 gave `paper` five roles. The literature strategist ran only when no `.bib` was held, and the citation compliance agent only in citation-check mode. The visualization agent ran in parallel with the draft writer, and a draft writer pass placed the figures. It limited the writer passes driven by other agents' issues to three. Four rulings of plan 5 change parts of that decision. Ruling J has the literature strategist run by default in full mode, always in outline-only, and in lit-review mode as that mode's work. The user reviews its sources in full, outline-only and lit-review, as in academic-paper's literature phase (`research-hub/.agents/skills/academic-paper/SKILL.md:90` and `:121`). Ruling S has the first draft mark where each figure goes and the visualization agent place its figures as its own patch. Ruling U has no writer pass follow draft review round 2, as academic-paper's round-2 rule has it: at most 2 revision loops, and unresolved issues become acknowledged limitations (`research-hub/.agents/skills/academic-paper/SKILL.md:137`). Ruling AF has the citation compliance agent run in full mode after the draft and in revision mode after the patches. academic-paper's full mode and revision run its citation compliance agent the same way (`research-hub/.agents/skills/academic-paper/SKILL.md:266-270`). A change of a decision takes a new record (`docs/adr/README.md`). The facts that led to 0022 stand. academic-paper names no integrity agent among its phases. academic-pipeline runs its integrity check at stage 2.5 and stage 4.5, after academic-paper's writing stage (`research-hub/.agents/skills/academic-pipeline/SKILL.md:103-111`). Roadmap entry 13, `researcher`, is the counterpart of academic-pipeline.

## Decision

`paper` is the counterpart of academic-paper, and its runs hold no integrity check and no ethics check. A full run is done by six roles. Each is a fresh agent started through the Agent tool with its own page under `skills/academic/paper/agents/`. It runs as `ordo-<reviewer_effort>` on the model the configuration's `reviewer` names:

- the literature strategist, which runs always in outline-only and lit-review mode and by default in full mode. Full mode skips it only when the user says so at intake or takes an earlier lit-review or outline-only run's outputs. In full, outline-only and lit-review mode the user reviews its sources before the run goes on
- a planner, which writes the outline and the argument map
- the draft writer, which writes the body, the abstract and the statements, and marks the place of each planned figure
- the visualization agent, started with the draft writer, which draws the figures and then places them by a patch of its own
- the citation compliance agent, which checks the citations of the draft against their sources. It runs in full mode before the draft review, in revision mode after the patches, and in citation-check mode as the whole run
- the peer reviewer, which gives the draft review.

The strategist and the visualization agent are each started once as a fresh agent. A second message through the runner's message tool resumes each in these cases and no other. The strategist is resumed in four cases: the review of its sources, the sections of the outline that have no source, the review of an expanded revision whose cause is insufficient evidence, and a patch the script rejected. The visualization agent is resumed for its placement patch and for a patch the script rejected. The planner's latest start is resumed for the review of an expanded revision whose cause is structural or one of originality. For every other change the planner is a fresh agent. No other agent receives a second message. After the draft the session runs `lookup.py cite-keys` and `check-urls` and gives their output to draft review round 1. No writer pass follows draft review round 2. Intake is the session's interview with the user. The integrity check and the ethics check belong to `researcher`. The integrity check covers the references, the claims against each source's full text, the numbers against the saved runs and the figures against their traces. `researcher` runs each check once on the finished draft and once after its revision.

## Alternatives rejected

- The strategist kept only when no `.bib` is held, as 0022 had it: a held `.bib` is then screened by no role. The sources the user holds are never searched for what they miss.
- A new strategist start for the review of its sources and a new visualization start for the placement: each start reads its inputs again and loses the search and the drawn figures. The spec counts each role once.
- A draft writer pass for the figures, as 0022 had it: the writer would place figures it did not draw. The visualization agent's patch makes that start unnecessary.
- A writer pass after draft review round 2: academic-paper ends the loop at round 2, and the issues left become acknowledged limitations in the final message.
- The citation compliance agent only in citation-check mode, as 0022 had it: a full or revision run would reach the draft review with claims that no one read against their sources. academic-paper runs the agent in both modes.
- The checks kept inside every run, as ADR 0019 had them: every run pays for checks that matter at submission. `researcher` would later run its own integrity stages on top of them.

## Consequences

A full run starts at most six roles. After the first draft the draft writer makes at most three passes driven by other roles' or scripts' issues. One answers the issues of draft review round 1, one the failing lines of the reference checks, and one the compile lines. A fourth pass follows only when the user answers the `/writing` report (ADR 0023), and a fifth only when the compile after that pass fails. Five cases add starts to that count, and each is named in the run's stops and steps. The user can choose an expanded revision at the stop "The draft review does not pass". It returns to the planner, the strategist or the sections, and resumes the planner or the strategist with the review. The draft writer then writes the first draft again or rewrites the sections as patches. The expanded revision adds a draft review round 1 and a round 2, with the reviews numbered on. The answer to lower the venue adds a draft review round 1 and a round 2 against the new venue, and the writer pass that round 1's issues need. The draft writer starts a second time to put the model identifier in the AI disclosure, when the runner's model list gave none and the writer was the first agent of the run. It starts a third time, once after the last change to the manuscript, to write the anonymous copy for a double-blind venue. The citation compliance agent starts again as a fresh agent after the stop "The citation style to confirm", and once more for the failing lines of the reference checks. Full, revision and citation-check runs check each cited claim against a passage read from its source, as ADR 0024 says, and a claim the run cannot support stops the run. Lit-review runs check no claim until `researcher` exists. `references/integrity-verification.md` and `references/ethics.md` leave `skills/academic/paper/`, and the coverage rows they held are marked `rebuild: researcher` with the commit that holds them. The later writing skills (`paper-review`, `rebuttal`, `grant`) have this record to follow or supersede.
