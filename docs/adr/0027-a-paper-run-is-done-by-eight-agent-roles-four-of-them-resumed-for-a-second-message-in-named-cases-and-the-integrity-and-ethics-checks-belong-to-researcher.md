# 0027. A paper run is done by eight agent roles, four of them resumed for a second message in named cases, and the integrity and ethics checks belong to researcher

Status: proposed; superseded by 0028 in the part that checks the numbers a run writes and its description of the data handling against the saved result files; superseded by 0029 in when the citation compliance agent runs and in its counts of starts and passes; superseded by 0030 in the effort and the model its roles run at; superseded by 0036 in its counts of starts, its list of resumptions and its sentence that no other agent receives a second message, in the draft review's stops, and in its sentence that a claim the run cannot support stops the run; superseded by the ruling The incremental change done properly of plan 5 in its count of roles, since the intake agent holds intake as a further role; superseded by 0043 in its roles, their starts and the modes they run in, now academic-paper's twelve roles with the intake agent only in full, outline-only, abstract-only, lit-review and plan mode, the integrity and ethics checks belonging to `researcher` standing; superseded by 0043 in its sentence that the session gives the output of `lookup.py cite-keys` and `check-urls` to draft review round 1, Phase 6b being given the contract's inputs alone

## Context

ADR 0025 names six roles of `paper` and decides "No other agent receives a second message". Ruling AK of plan 5 builds academic-paper 3.2.0's `plan` and `format-convert` modes in `paper` (`.scratch/5-paper/plan.md`, Rulings), as step 4.A. In academic-paper the Socratic mentor holds a dialogue with the user over many rounds: at least 2 rounds per chapter over six chapters, 20 to 30 rounds in a typical run, and an offer to stop after more than 8 rounds on one chapter or more than 30 in all. It tracks the convergence signals of each chapter across those rounds (`research-hub/.agents/skills/academic-paper/agents/socratic_mentor_agent.md`, "Convergence Criteria" and "Convergence Mechanism"). Its "Mid-Process Save" records the chapters done, the chapter in progress, the signals of each chapter and the INSIGHT collection. academic-paper's `format-convert` mode runs its formatter alone (`research-hub/.agents/skills/academic-paper/SKILL.md:273`), and the formatter makes DOCX "via Pandoc when available" (`agents/formatter_agent.md`, "Supported Output Formats"). Neither role is among 0025's six. Open item AY of plan 5 put three ways of running the mentor to the user, who ruled (a), the mentor kept as one agent across the dialogue. A change of a decision takes a new record (`docs/adr/README.md`).

## Decision

`paper` is the counterpart of academic-paper, and its runs hold no integrity check and no ethics check. A full run is done by six roles, a plan run by the Socratic mentor and the planner, and a format-convert run by the formatter. Each is a fresh agent started through the Agent tool with its own page under `skills/academic/paper/agents/`. It runs as `ordo-<reviewer_effort>` on the model the configuration's `reviewer` names:

- the literature strategist, which runs always in outline-only and lit-review mode and by default in full mode. Full mode skips it only when the user says so at intake or takes an earlier lit-review or outline-only run's outputs. In full, outline-only and lit-review mode the user reviews its sources before the run goes on
- a planner, which writes the outline and the argument map
- the draft writer, which writes the body, the abstract and the statements, and marks the place of each planned figure
- the visualization agent, started with the draft writer, which draws the figures and then places them by a patch of its own
- the citation compliance agent, which checks the citations of the draft against their sources. It runs in full mode before the draft review, in revision mode after the patches, and in citation-check mode as the whole run
- the peer reviewer, which gives the draft review
- the Socratic mentor, which in plan mode guides the user chapter by chapter to the chapter plan, as academic-paper's `agents/socratic_mentor_agent.md` does
- the formatter, which in format-convert mode writes the patches that give the manuscript its citation format, its venue's template and its format profile, and the report, as academic-paper's `agents/formatter_agent.md` does for its conversion. The session then makes the output formats with `pandoc` and `latexmk`.

The strategist and the visualization agent are each started once as a fresh agent. A second message through the runner's message tool resumes each in these cases and no other. The strategist is resumed in four cases: the review of its sources, the sections of the outline that have no source, the review of an expanded revision whose cause is insufficient evidence, and a patch the script rejected. The visualization agent is resumed for its placement patch and for a patch the script rejected. The Socratic mentor is resumed with each answer of the user in plan mode, and after each round it writes the checkpoint of academic-paper's "Mid-Process Save" into the run folder, so a run continued in another session starts a fresh mentor from that checkpoint. The planner's latest start is resumed for the review of an expanded revision whose cause is structural or one of originality. For every other change the planner is a fresh agent, and in plan mode it is a fresh agent for the outline from the chapter summaries, for each evaluation of the stress test and for the chapter plan. No other agent receives a second message. After the draft the session runs `lookup.py cite-keys` and `check-urls` and gives their output to draft review round 1. No writer pass follows draft review round 2. Intake is the session's interview with the user. The integrity check and the ethics check belong to `researcher`. The integrity check covers the references, the claims against each source's full text, the numbers against the saved runs and the figures against their traces. `researcher` runs each check once on the finished draft and once after its revision.

DOCX and Markdown output is made by `pandoc` when it is on the PATH, and named in the final message when it is not, as a missing `latexmk` is. A PDF is made only from the `.tex` by `latexmk`, never from a `.docx`.

## Alternatives rejected

- ADR 0025's decision as it stands: plan mode and format-convert mode have no role to run them, and the mentor could not hold the dialogue as one agent.
- A fresh mentor agent for each round, given the run's dialogue record: 20 to 30 starts, each reading the mentor page and the record again, so each answer of the user waits for a new start, and what the user said that the record does not hold is lost between rounds.
- The session holding the dialogue itself from the mentor's page, as it holds intake: it departs from academic-paper, where the mentor is an agent of its own, and the session judges convergence while it also runs the mode.
- The strategist kept only when no `.bib` is held, as 0022 had it: a held `.bib` is then screened by no role. The sources the user holds are never searched for what they miss.
- A new strategist start for the review of its sources and a new visualization start for the placement: each start reads its inputs again and loses the search and the drawn figures. The spec counts each role once.
- A draft writer pass for the figures, as 0022 had it: the writer would place figures it did not draw. The visualization agent's patch makes that start unnecessary.
- A writer pass after draft review round 2: academic-paper ends the loop at round 2, and the issues left become acknowledged limitations in the final message.
- The citation compliance agent only in citation-check mode, as 0022 had it: a full or revision run would reach the draft review with claims that no one read against their sources. academic-paper runs the agent in both modes.
- The checks kept inside every run, as ADR 0019 had them: every run pays for checks that matter at submission. `researcher` would later run its own integrity stages on top of them.

## Consequences

A plan run starts one mentor, which holds the whole dialogue, and fresh planner starts for the outline, each evaluation of the stress test and the chapter plan. The mentor's context grows over the rounds of the dialogue, and its resumption depends on the runner keeping the agent, which the checkpoint in the run folder covers. A format-convert run starts the formatter once, and again as a fresh agent only for a patch the script rejects as `validation` or `schema`, for a structural patch the user refuses, as every role that is not resumed does, and for the conversion patch of a run that changes the citation style with a DOCX or Markdown target. That second start follows the compile of the conversion copy after the first patch, so the numbers and the reference list the conversion patch prints are those of the new style. A runner without `pandoc` gets no DOCX or Markdown output, and the final message names `pandoc` as missing. A full run starts at most six roles. After the first draft the draft writer makes at most three passes driven by other roles' or scripts' issues. One answers the issues of draft review round 1, one the failing lines of the reference checks, and one the compile lines. A fourth pass follows only when the user answers the `/writing` report (ADR 0023), and a fifth only when the compile after that pass fails. Four cases add starts to that count, and each is named in the run's stops and steps. The user can choose an expanded revision at the stop "The draft review does not pass". It returns to the planner, the strategist or the sections, and resumes the planner or the strategist with the review. The draft writer then writes the first draft again or rewrites the sections as patches. The expanded revision adds a draft review round 1 and a round 2, with the reviews numbered on. The draft writer starts a second time to put the model identifier in the AI disclosure, when the runner's model list gave none and the writer was the first agent of the run. It starts a third time, once after the last change to the manuscript, to write the anonymous copy for a double-blind venue. The citation compliance agent starts again as a fresh agent after the stop "The citation style to confirm", and once more for the failing lines of the reference checks. Full, revision and citation-check runs check each cited claim against a passage read from its source, as ADR 0024 says, and a claim the run cannot support stops the run. Lit-review runs check no claim until `researcher` exists. `references/integrity-verification.md` and `references/ethics.md` leave `skills/academic/paper/`, and `researcher` takes what they held. The later writing skills (`paper-review-panel`, `rebuttal`, `grant`) have this record to follow or supersede.
