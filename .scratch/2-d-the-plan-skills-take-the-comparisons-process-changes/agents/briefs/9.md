## Cases

The script (items 4 and 5), each a scratch-repository test with its exit status and line:
- Both blocks equal their templates: exit 0, an `ok:` line for each.
- The glossary block differs by one line: exit 1, the diff under `docs/glossary.md`; the shared-rules block equal.
- Both blocks differ: exit 1, both diffs.
- `--write` with both differing: exit 0, both rewritten, every byte outside the markers kept, a CRLF glossary written back in CRLF.
- No `docs/glossary.md`: exit 2 with the new `error:` line.
- A glossary with no block, with two blocks, or with the end marker before the begin marker: exit 2 with the new `error:` line.
- A glossary that is not UTF-8: exit 2, `error: <path> is not UTF-8 (byte <n>)`.
- `plan-terms.md` missing beside the script: exit 2, `error: cannot read <path>: <reason>`.
- `--only glossary` in a repository with no `CLAUDE.md`: exit 0 on an equal block, 1 on a differing one.
- `--only` with another value, or two paths: the usage line, exit 2.
- The shared-rules block drifted and no glossary, with and without `--write`: exit 2 with the glossary's `error:` line, nothing on stdout, `CLAUDE.md` byte for byte unchanged.
- `CLAUDE.md` with no single block and no glossary: exit 2, two `error:` lines, `CLAUDE.md`'s first, nothing on stdout.
- `--write` with only the glossary block differing: exit 0, the shared-rules `ok:` line and the glossary's `written:` line, `CLAUDE.md` byte for byte unchanged.
- `--write` where `CLAUDE.md` cannot be written: exit 2 with its `error:` line, the glossary not written.
- `--only glossary` with a drifted or missing shared-rules block in `CLAUDE.md`: exit 0 on an equal glossary block.
- `--only glossary --write` on a differing glossary: exit 0, only the glossary rewritten, a present `CLAUDE.md` byte for byte unchanged.
- `--only` last with no value, `--only=glossary`, `--only glossary` twice: the usage line, exit 2. `--only glossary` before the path: accepted.
- `docs/glossary.md` a directory: exit 2, `error: cannot read <path>: Is a directory`.
- A glossary that is not UTF-8, under `--write`: exit 2 and the file byte for byte unchanged.
- The glossary cannot be written, or does not read back: exit 2 with `error: cannot write <path>: <reason>` or `error: <path> does not read back as written`.

## Decisions taken in this brief (each reversible, none silent)
