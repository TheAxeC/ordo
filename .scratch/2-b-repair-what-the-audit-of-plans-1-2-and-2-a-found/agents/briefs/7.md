## What to build

1. **`utils/check_skill_layout.py`**, each fix with the case of the test that is red without it:
   - Lines split on `"\n"` only (the file read with `newline=""`, a trailing `"\r"` stripped from each line), so line numbers match `grep -n` and an editor.
   - A UTF-8 byte-order mark at the start of the file is not text: the file is read with `utf-8-sig`.
   - `__` is bold only when not between word characters; `**` stays bold everywhere outside code; a label `__Label.__` is still a label.
   - A heading indented by one to three spaces is read as the heading it is.
   - Each of the tables of Use instead, Stops and Anti-patterns needs at least one row after its separator.
   - A version tag in a heading is `v<digits>` as a word or a bare `<n>.<n>.<n>`; a top-level `version` key in the frontmatter is an error, since the version lives in `metadata.version` only.
   - An empty frontmatter is reported as "frontmatter is empty".
   - The docstring states each of these.
2. **`utils/check_skill_layout.test.sh`**: a case per fix above, each red under the revert of its fix, and the untested behaviour of finding 7 covered: a label `- __Paths.__ x`, a table header with an extra column (`| When | Use | Note |`), and a file holding the byte `\xe9` (not UTF-8).
