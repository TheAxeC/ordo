## What to build

1. **Done lettered entries.** `ROADMAP_ENTRY` accepts a done entry written `- [x] <n>.<letter>. ` as well as `- [x] <n>.<letter> ` and `- [x] <n>. `.
2. **Lines split on newlines only.** Every split of the list, the roadmap and `find`'s output splits on `\n` only (use `find -print0` for file names), so a name holding U+2028 or U+0085 stays one name.
3. **One Unicode form.** File names from `find` and the file cells of the list are compared in NFC.
4. **A mode for built rows.** A new option, `--built <skill>` (repeatable), checks that every row marked `rebuild: <skill>` for each named skill has a reason that names, in backticks, a path that exists under `skills/<skill>/` of the repository that holds the coverage list; a row that names none, or names one that does not exist, is an error with its line. Without the option the check behaves as today.
5. **Tests.** `utils/check_coverage.test.sh` gains a case for each item, each red under the revert that undoes it, and cases for the three untested behaviours (a `find` that fails, exit 2; a last cell ending in `\|` with no closing pipe; the output order). The head comment names the cases.
6. **The docstring and usage line** name `--built`.
