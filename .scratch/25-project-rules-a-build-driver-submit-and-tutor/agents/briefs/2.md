## Cases

Each case is checked by reading the pages named.

- A full-mode run whose declared format profile sets a font size, with a venue page limit, whose compile log gives one page more than the limit: expected: no layout value is changed, and the manuscript goes back to the draft writer once with the patch id `limit-cut`.
- A full-mode run whose manuscript is over a declared word limit after the formatter's patches: expected: one return, the compile and the count again, the incremental citation check of the cut's patch, then the targets.
- The same run, still over after the one return, or over again after the findings pass: expected: no second return, and the final message names each section's length against the limit.
- A format-convert run whose manuscript is over the venue's word limit: expected: nothing is cut, no layout value is changed, and the final message names it.
- A `grant` run in `revise` whose compile is over the page limit: expected: one return to the draft writer, as in `draft`.
- A `grant` draft whose last compile is one page over the limit: expected: one resume of the draft writer to cut content, the compile and both scripts again, and the final message gives each section's length against its limit when still over.
- A `grant` form field over its limit: expected: unchanged, the existing sentence.
- A manuscript sentence "In an earlier version of this section we reported the effect differently": expected: the new rule of the manuscript prose standard names it as process history, and a review agent of `/writing` has the rule in its list.
- `grep -rn 'venue-compliant' skills` after the step: expected: no line.
- A verbatim block wider than the page: expected: the formatter's sentence on a smaller font for it is unchanged.

The builder's first task, before any change, is the first read of every case above on the unchanged tree, with each case's result noted.

- A case of a text or judgment step is checked by reading the unchanged tree.

When the first read finds a case the brief's own rules get wrong, the builder stops there, before changing anything, and hands back that case, with the rule and the result it gives.

## Conventions

ASCII only. One paragraph or bullet per line, no hard wraps. No em dash, no history, no date, no step or entry number in any shipped file. A shipped file names nothing private, and an example is made up and says so. The pages of `paper` keep academic-paper's wording outside the sentences this step changes.
