## What it must do

- **Finding an agent's plan and role.** For each `meta.json`, read its `toolUseId` and `spawnDepth`. For depth 1, find that `tool_use` in the parent session's file and read the description and prompt; for depth 2, find it in the parent subagent's transcript. Read the agent's completion notices by `<task-id>`, each counted once. Match each notice's tokens and tool uses to a booking's Usage entry. An agent no booking names is placed by its prompt (the worktree, the ledger folder, the brief's path) or, when its prompt names no plan, by the parent session's timeline against the ledger's commits (`git log --format='%h %ad %s' --date=iso`), and its place is stated in the report with the evidence.
- **The roles.** "brief check" is `brief check of step <n>`; "builder", a trial build included, `builder of step <n>`; "reviewer", a trial reviewer and a stopped or relaunched reviewer included, `reviewer of step <n>`; "reviewer over round 1" `reviewer of step <n> over round 1`; a `/grill` lookup `grill lookup`. `<n>` is the step as its booking heading or its brief's path names it (`12a`, `2b`, `3a`).
- **The served model.** The `message.model` of the agent's transcript's assistant entries other than `<synthetic>`; an agent with two such models is reported and listed with the model of most of its responses; an agent with no transcript is a numbered item, not a bullet.
- **The counts.** For each booked step, the number of bullets per role equals the booking's number for that role plus the agents the report names as started for the step and not booked (stopped, relaunched, trial, or of a reverted run), each named.
- **Where the files are written.** The files are ledger files of the main checkout, written there by the orchestrating session (Decision 1); the worktree is not changed.
- **Commands, not scripts.** The reading is done with one-off `python3 -c` or heredoc commands run from the scratchpad, each printing facts (records, figures, matches), with no file added to the repository; the matches are read and judged by the session.
