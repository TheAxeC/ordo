   - The merge run has no cut sources to judge: `literature-strategist-merge-run.md:15` goes, and the merge run keeps every source of the theme runs that passes the shared criteria again (`:14`).
   - `SKILL.md`, "The theme search", gives each search theme a target count in place of a range, written in `config.md` as "Target: at least <n> sources"; `SKILL.md:520` and every other sentence that names a theme's range read the target.

Layer 1's decision for over 500 records reads "tighten it with qualifiers, or split it into one string per recorded part", with no narrower year range (`:135`); ADR 0040 names this as a deviation from academic-paper 3.2.0.

ADR 0040 names both as deviations.
