Each mode of paper as your rulings of 2026-10-20 make it (open items J to AB in plan.md's Rulings), beside the same mode of academic-paper 3.2.0, research-hub's copy. The skill on main is paper 1.0.0, step 4's base, and does not do this yet; step 4 builds it to this page (your ruling on Q).

Two rulings hold for every mode and are not drawn: an unfinished run is offered for continuing, its finished steps skipped (Z), and intake of full and outline-only offers an earlier lit-review's review and .bib and an earlier outline-only's approved outline, which full then skips (Y). A plain request, such as /paper please improve section 3, picks the mode, which the intake confirmation shows; a request that fits two modes is asked about before intake, and the mode name still works (AB).

The page has two views of each mode. The simple view draws the agents, the stops and the cycles, which set what a run costs. The detailed view draws every step, script and stop from each skill's files.

What a run costs

The count is the agent starts of a run of each mode: the fewest, and the most when every agent that runs only when needed does run and every cycle with a cap goes round once. Your own changes at intake and at the outline are not counted, since each adds one start in both skills. A cycle with no cap is named, not counted.
