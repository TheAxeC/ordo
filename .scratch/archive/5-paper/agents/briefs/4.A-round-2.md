### Ruling BA

9. R Behaviour 2, F29 and K8, ruling BA (a). When a run changes the citation style and has a DOCX or Markdown target, the order of format-convert is:
   - the formatter's first start writes the manuscript patch and the report, and no conversion patch;
   - the session applies the manuscript patch to the conversion copy (and to the manuscript, as round 1's ruling 26 says) and compiles the copy;
   - the session starts the formatter a second time as a fresh agent, given that compile's `.aux` and `.bbl`, the copy's manifest and the first start's report; it writes only the conversion patch, the citations in the new style;
   - when the style does not change, the one start writes both patches, as built.
   - `--citeproc` runs only for an author-year style with no numbers in the `.aux`, with the CSL file when one is held, and `SKILL.md` and `formatter.md` give the same rule (K8).
   - ADR 0027's sentence on the formatter's starts names this second start, refined in place.
   - Run the case on a scratch copy of the probe (`../research-hub/projects/manuscripts/covert-theory/manuscript/`, read only at its source) with its `\bibliographystyle{IEEEtran}` changed in the scratch copy to an author-year style of the installed TeX (such as `plainnat` with `natbib`), converted to IEEE with a `docx` target: write the two patches yourself as the formatter's page says, apply them by `apply_tex_patch.py`, and quote the first citation and the first reference entry of the DOCX text, which are in IEEE form.
