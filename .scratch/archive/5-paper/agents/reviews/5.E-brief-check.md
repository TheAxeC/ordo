## 6. Implied inputs

These are inputs to `lookup.py text`, the code part of the step. Each has happened, or a wrong answer on it costs something.

- **A page that is not UTF-8.** An older publisher page in Windows-1252 or ISO-8859-1 with a `<meta charset>` has happened. `read_text_file` (`lookup.py:1483`) refuses such a file with "not valid UTF-8" (exit 2). `fetch` decodes by the reply's charset with `errors="replace"` (`:285`-`:290`).
  - Expected result: the text is made, decoded by the page's declared charset, else as UTF-8 with replacement, as `fetch` does. A refusal would make the agent fall to "abstract only".
  - Missing from Cases.
- **A UTF-8 BOM before `<`.** `'<byte order mark>'.isspace()` is false, so "first non-blank characters are `<`" fails on such a page.
  - Expected result: the file is read as HTML or XML.
  - Missing.
- **An XML declaration and a DOCTYPE before `<article>`.** Expected result: read as XML, the text made.
  - Missing; low cost.
- **`pdftotext` exits non-zero, times out, or leaves a partial `<stem>.txt`.** Expected result: `<file>: no text`, exit 1, and no `<stem>.txt` left behind.
  - Missing. A partial file left behind would trigger T5's refusal and block the next way's text for that source.
- **`pdftotext` not installed.** Item 3 says "cannot read" gives `<file>: no text`. That sends the agent to the next way and possibly to "abstract only", although `fetch` names this condition ("pdftotext not found").
  - Expected result: a line naming that `pdftotext` is not found.
  - Missing, and the brief does not say which result it wants.
- **A `<file>` path with a space or a single quote, or starting with `-`.** Rule 15 of `docs/dev/change-standard.md` applies: a supplied value reaching a command. `parse_options` (`:1446`) passes a single-dash argument such as `-layout` as positional.
  - Expected result: `pdftotext` gets the absolute path as one list element, as `FetchRun` passes `os.path.abspath` paths, and the text is made.
  - Missing.
- **`<folder>/<stem>.txt` is a symlink, or a dangling one.** Expected result: refused as existing (exit 2), with nothing written through the link.
  - Missing. `os.path.exists` is false for a dangling link, and `open(..., "w")` would follow it.
- **Two keys whose stems collide** (`a/b` and `a:b` both give `a_b`). Expected result: the second is refused with `error: <folder>/a_b.txt exists`, exit 2, by T5's rule.
  - Covered by T5's rule; no case names it.
- **An empty file.** `curl --fail` may leave none or an empty one. Expected result: `error: <file>: not an HTML, XML or PDF file`, exit 2.
  - Missing; low cost.
- **A very large file.** Expected result: `pdftotext`'s 120 s timeout, as in `fetch`, gives `<file>: no text`, exit 1; a large HTML page is parsed whole.
  - Not stated.
- **Values outside `text` that reach a command.** These are rule 15 cases in the agent's `curl` command.
  - A DOI in the Europe PMC query address and in `https://doi.org/<DOI>`: a DOI with `<`, `>`, `;`, `#` or `(` breaks the query or truncates at `#`.
  - The strategist's page encodes query values with `curl -sS -G '<interface address>' --data-urlencode 'term=<string>'` (`literature-strategist.md:84`). The dictated command for the agent has no such encoding.
  - Expected result: query values percent-encoded as `:84` does.
  - Missing.
- **Earlier papers given as a path or as a citation.** `intake.md`'s Earlier papers row allows "a path, a DOI or a citation".
  - Expected result: a local file is read directly, or made into text with `lookup.py text` under a stated key; a citation is resolved to an identifier first.
