## Content integrity

- [x] C1. Text of manuscript.tex matches draft_v6 sentence for sentence. Method: strip LaTeX markup from the body of manuscript.tex (from `\begin{document}`) and Markdown markup and HTML comments from draft_v6 with the two sed scripts below, split both into one word per line, and compare with `diff`. Both sides drop braces, so math is compared token by token.

    ```
    sed -n '/\\begin{document}/,$p' manuscript.tex | sed 1d | sed -E -f tex2words.sed | tr -s ' \t' '\n\n' | grep -v '^$' > tex.words
    sed -f md2words.sed draft_v6.md | tr -s ' \t' '\n\n' | grep -v '^$' > md.words
    diff md.words tex.words
    ```

    `tex2words.sed` (run with `sed -E`): delete lines starting `%`; remove `\cite{..}`, `\label{..}`, `\tnoteref{..}`, `\tnotetext[..]`, `\refstepcounter{..}`, `\includegraphics[..]{..}`, the `tabularx` column spec, `\begin{..}[..]`, `\end{..}`, `\renewcommand{\thetable}{S1}`, `\bibliographystyle{..}`, `\bibliography{..}`; remove the command names `\textbf{ \textit{ \texttt{ \section*{ \section{ \subsection{ \title{ \author{ \caption{ \gapbox{` and `\noindent \item \toprule \midrule \bottomrule \smallskip \raggedright \centering \small \footnotesize \scriptsize`; map ` \sep ` to `; `, `\[ \]` to `$$`, `$^{-3}$` to `^-3`, TeX quotes to `"`, `\%` to `%`, `\_` to `_`, `~` to a space, ` & ` to a space; drop the row end ` \\` and all braces. `md2words.sed`: remove `<!--..-->` comments and `[key]` citations; drop heading hashes, table separator rows, table pipes, `**`, `*`, list dashes, backticks and braces.

    Result: 41 diff hunks. Each one is a label that the LaTeX template generates, a move that the template requires, or the line replaced by the bibliography. The table counts items: the keyword move and the heading number `1.` fall in one hunk, and the image alt text and the `Figure 2.` label in another.
