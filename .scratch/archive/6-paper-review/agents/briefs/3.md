## What to build

The six edits, by number:

1. This repository's names for the source's files, roles and records.

## Conventions

- The page is written for a person: plain short sentences, the same word for the same thing each time, no praise and no summary of what the steps did.
- Printable ASCII only, no hard wraps, no em dash. A character outside the set in quoted text is written by its name in angle brackets, such as `<em dash>`, `<not-equal sign>` or `<check mark emoji>`. Chinese text is written as `<Chinese text, n characters>`. Every other character outside the set is written by its name the same way: `<right arrow>`, `<section sign>`, `<greater-or-equal sign>`, `<en dash>`, `<warning sign emoji>`; the invisible variation selector after an emoji is part of the emoji's name and is not written. The page holds no green checkmark, though the check of "Verify before you report" allows one in a Markdown file.
- A file's part opens with a heading of the file's path. The heading is `## <path>`, the path as `diff -r` gives it under the skill's folder, such as `## agents/eic_agent.md`, and no other heading of the page begins with `## ` followed by a path. An entry is a list item or a table row. Quoted text that holds no backtick stands in backticks. Quoted text that holds a backtick or a code fence stands in a fenced block whose fence is longer than any run of backticks inside it.
