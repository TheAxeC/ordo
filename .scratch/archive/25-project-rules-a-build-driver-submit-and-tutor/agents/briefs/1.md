## What to build

Five rules are written, each on the pages ruling D3 names. Each rule is worded by the builder in the form of its neighbours on the page, and says exactly what its line below says, no more and no less.

The five rules:

- R1, targets: every target in scope of a change (each platform, configuration or build the change is meant for) compiles and works in the same change; a target is never left broken for a later change.
- R2, open items: an open item is raised to the user only for options that each cost something the user would weigh.
- R3, wishes: every option offered to the user meets every wish the user has stated; an option that drops one is not offered.
- R4, effort: a question about how much effort something is gets an answer that lists each change and the code it touches, and gives no duration.
- R5, YAML: a YAML file is loaded, that is parsed as YAML, after every write to it.

Where each goes:

   - R1 is one new bullet directly after "Zero warnings". The line "Zero warnings" itself is not changed.
   - The rule "No history in a rule file or a comment" stays the last rule.
   - R2 says nothing that contradicts "No question boxes" or the self-rule sentence in it.
