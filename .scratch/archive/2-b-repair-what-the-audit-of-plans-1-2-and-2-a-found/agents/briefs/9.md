## What to build

In `skills/repo-setup/templates/sync_rules.py` and its test:

1. **Exit 2 on what it cannot read.** A `CLAUDE.md` or `shared-rules.md` that is missing or not UTF-8 is an error line and exit 2, never a traceback or exit 1.
2. **Line endings kept.** `--write` keeps every byte outside the block as it was, and writes the block with the file's own line ending (CRLF when the file uses CRLF).
3. **Errors on stderr.** Every `error:` line goes to stderr; the `ok:`, `written:` and diff lines stay on stdout.
4. **Tests.** Cases for: a `CLAUDE.md` not in UTF-8 (exit 2); a missing `shared-rules.md` (exit 2); CRLF kept by `--write`; reversed markers; two blocks; no `CLAUDE.md`; the text before the block kept byte for byte by `--write`; the re-read after writing (a write that does not take is an error); errors on stderr. Each case red under the revert that undoes what it checks, including each of the five planted faults above.

In `skills/land/templates/land.sh`, `usage.py` and `land.test.sh`:

5. **Nothing pending lands.** The worktree's wip commit is made only when something is staged; a builder that committed everything lands. A test case covers it.
6. **The example check never skips inside an Ordo checkout.** When `land.test.sh` runs from inside an Ordo checkout (the repository around it holds `skills/plan/templates/`), a missing example file or state template is a failure, not a skip; the skip stays only for a copy outside any Ordo checkout, and says so. A test covers both.
7. **A bounded lock wait.** `wait_for_index` stops after a bound (60 s of waiting) with a message that names the lock and exit 1, whatever processes run; a stale lock with no `git` process running is still removed as now. A test with a lock held and a stand-in `git` process running shows the bounded stop, with the bound shortened for the test through an environment variable the head comment names.
8. **Codex messages counted as messages.** For a Codex rollout, the count is the assistant messages in the window (`response_item` entries whose payload is a `message` with role `assistant`), so the printed `<n> messages` means the same for both harnesses; the token figures stay the `token_count` difference. 9. **A time without an offset refused.** `usage.py` refuses a window time that has no offset or cannot be read, with a message naming the time and exit 64; a log line whose own timestamp lacks an offset is skipped, as a bad one is now. Test cases for both window arguments.
10. **The texts.** `skills/land/SKILL.md` Steps 3 says the wait for `.git/index.lock` is bounded and what happens at the bound. The `README.md` bullets of `land.test.sh` (line 117) and `sync_rules.test.sh` (line 120) say what the tests cover. The head comments and docstrings say each behaviour above.
