2. **Each cause ended.** Where the code breaks a bound it promises (the note's 3-second limit, the scanner's 2-second limit, the land skill's five-second wait, the guard's tenth of a second), the code is fixed so it keeps the promise under load. Where the test measures the wrong interval, or looks once where it must wait, the test is fixed to measure what the case states. A bound that states a promise of the code is never widened to make a case pass.
