It follows research-hub's form in the drawing only (the layout, the card with its top rule and bold title, the arrows and their markers, the captions, the `aria-label`, ASCII-only output, one printed line per file written), with the palette's exception under "Colours" below; its Python follows `python.md`, `common.md` and `design-principles.md`, not research-hub's code: `pathlib.Path`, `encoding="utf-8"`, annotations, no third-party import (Python standard library only, `libraries: avoid`), and the errors below printed to stderr with a non-zero exit, never an `assert`. Written anew for Ordo, with no code comment carrying history and no reference to research-hub in the file.
   - Paths are taken from the script's own location, so it runs the same from any directory; it writes into its own folder.
   - Before writing, it checks that every label fits: each label's wrapped lines, at a character budget computed from the box's width and the font size with a conservative width per character, fit the box's lines; a label that does not fit is an error naming the figure, the box and the label, exit 1, nothing written.
