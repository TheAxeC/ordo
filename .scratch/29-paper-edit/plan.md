## Goal

`paper` has the mode `edit`, `/paper edit <main.tex> <edits file>`, which fills `[GAP: ...]` markers from the user's answers and makes small stated changes such as an author, an affiliation, a funding line or an email, by one patch of the draft writer applied by script, with a word-level diff per op and no peer reviewer, change list, re-review or closing review. A gap is filled by a `fill_gap` op whose new block `apply_tex_patch.py` builds itself, and `apply_tex_patch.py --allowed-blocks` refuses an op on a block that `anchorize_tex.py --find` did not find holding an item's marker or old text in the main `.tex`, the files it inputs and `cover-letter.tex`, or of a kind that block does not allow; an op that adds a cite command gets the incremental check's work from a fresh citation compliance agent, the compile runs, and an item that changes a claim, a result number or what a citation supports is refused alone, named in the final message with the writer's reason and that `/paper revision` takes such a change, and never routed to it; the mode stands in every page, figure and count of the repository that lists `paper`'s modes, and ADR 0062 records it.
