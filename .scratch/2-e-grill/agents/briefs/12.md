   - **Terms and claims** (as `domain-modeling` does): a term the user uses that the glossary lacks, or uses in more than one sense, is sharpened by a decision of its own; a relationship between terms is tested with a concrete scenario in that decision; a claim the user makes about the code is checked against the code by a lookup before a decision rests on it, and a mismatch is shown.
