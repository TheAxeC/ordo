3. `skills/ordo-init/templates/check_config.py`:
   - A key written twice in a mapping is refused for every key, since the loader would keep the last value without a word: `key written twice: <key>`. The file is loaded with a safe loader that raises on a duplicate key; the error names the key (in the projects form, with the project's prefix when the duplicate is inside a project).

A trailing slash is accepted.

   - `worker_effort` and `reviewer_effort`, when present, must be exactly one of `low`, `medium`, `high`, `xhigh`, `max`: `<key> is not low, medium, high, xhigh or max: <repr>`, an empty value, a number, a boolean and other capitals included.

## Decisions taken in this brief (each reversible, none silent)

1. The key names, values, defaults and comments are the ones rulings G2, G4, O1 and O4 set; the comment wording is taken here.
2. An empty value of a new key is an error, as `libraries` treats it, since a key written with no value is a mistake rather than a choice of the default.
3. `adr` is checked when present (ruling O1). A missing folder is an error, except the default `docs/adr`, which is a note: the example writes `adr: docs/adr`, `README.md` tells a reader to copy the example, and a repository gets that folder from `repo-setup` or when `grill` writes its first record. `README.md` then stays true unchanged.
4. `adr` must stay under the repository root, since every path in `plan.yaml` is relative to it and `grill` writes into that folder.
5. For the five keys the value check replaces the kind check, so one wrong value gives one line.
6. A key written twice is refused for every key: the loader would keep the last value silently, which the change standard's rule 15 names as an edge to exercise, and the fix is one loader for the whole file.
7. The several-projects example keeps one `adr` folder for the repository, `docs/adr`.
8. The five keys go after `bench` in every file, so the existing order is kept.
9. The version lines of the skills whose `SKILL.md` this step changes are not raised here; the closing of the plan raises them.
