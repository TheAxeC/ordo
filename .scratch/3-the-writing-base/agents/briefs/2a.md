2. **LaTeX data rows** (ruling E). A LaTeX line whose text is one command with its bracketed arguments is running prose, counted by `semicolons`, when either:
   - its command is one that carries prose: `\footnote`, `\caption`, `\emph`, `\textbf`, `\textit`, `\textsl`, `\textsc`, `\underline` (starred forms too); or
   - it is a brace group opened by a size or font switch: `{\tiny`, `{\scriptsize`, `{\footnotesize`, `{\small`, `{\normalsize`, `{\large`, `{\Large`, `{\LARGE`, `{\huge`, `{\Huge`, `{\itshape`, `{\bfseries`, `{\em`, `{\it`, `{\bf`, a switch possibly followed by further commands before the text (`{\footnotesize\color{inkgrey}\textbf{Figure 1.} ...}`).

   Every other one-command line stays a data row, and so do the lines after it that hold only its further bracketed arguments. A line of only bracketed arguments that follows a line that is not a data row (such as a `{\small ...}` group after `\noindent`) is a brace group, read by the second rule. The head docstring states both lists and the rule in these words.
3. **The contrast window and code spans.** A removed Markdown code span ends the contrast window, so no contrast match spans the place of a code span. No other check's output changes: the test's samples and cases give the same flags as before, apart from the cases this step adds.
