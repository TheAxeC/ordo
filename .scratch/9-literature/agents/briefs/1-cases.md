# Step 1, round 0: the ruling on the cases

The builder's first run found that T5's last assertion contradicts item 9's rule for `quote-check`, and asked for a ruling. The rulings below are the orchestrator's, inside the step's part; the brief stands in every other point.

1. T5, its last assertion. Ruled (a): `quote-check` keeps item 9's rule, found meaning the normalised passage occurs in the normalised text, as D11 and ADR 0017 say. The last assertion of T5 reads: the passage "mutual information estimation" (one word changed) is not found in a text holding "mutual infor-\nmation   estimators". Checked: with the brief's normalisation, "mutual information estimation" in that text gives False, and "mutual information estimator" gives True, since "estimator" is a prefix of "estimators". No word-boundary condition is added, since that would be a computation the user has not approved.
2. C14, the pacing. Every arXiv paper probed on 2026-10-17 has an HTML page (`https://arxiv.org/html/<id>` answered 200 for 2511.18945, 1801.04062, math/0601001 and six others), so a `fetch` of a real paper makes one arXiv request. The pacing is shown by a run with an id that does not exist: `time python3 skills/literature/templates/lookup.py fetch 2511.99999 <scratch> none` tries the arXiv HTML (404, probed) and then the arXiv PDF, and the quoted `time`, with the URLs it prints, shows at least 3 seconds between the two arXiv requests; it exits 1. C14 keeps its fetch of `gritsai2025` and its `quote-check` runs, the changed word chosen so that it is no prefix or extension of the source's word. C15 is the naming case only.
3. HTML text. Confirmed: when `fetch` strips an HTML page to `<key>.txt` with `html.parser`, the text inside `<script>` and `<style>` elements is left out, since it is not the paper's text.
4. BibTeX from doi.org. A body whose first character other than whitespace is `@` counts as a BibTeX entry, so the leading space doi.org returns is accepted. The entry is printed as doi.org gives it, characters outside ASCII included; the character-set check covers the repository's files, not the script's output.

The builder's final report carries these rulings under "The cases' first run".
