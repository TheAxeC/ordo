## What to build

### 1. The merge run does the work the theme runs hand on

In `SKILL.md` "The prompts of a literature search", the merge run's list:

- The last sentence of `:879`, "It makes no other search.", goes. The gates and their failure handling run after the work below.
- A rule says that the merge run assesses on its merits, with a live lookup, every source a theme run hands on: a lead the theme run names for the merge run, a source it left out to hold its target, a work it could not confirm, and a work its open citation loop leaves.
- A rule says that the merged set has no per-theme target.
- A rule says that each source handed on is included or excluded with its reason, and the report lists each with its decision.
- A rule says that where a theme run reports its citation loop open, the merge run runs one backward-chaining round over the merged core set, named in the report, and one forward-tracking round over the last three years, screens what they return and reports whether the loop closes.
- A rule says that the merge run searches the intersections of the search themes that the research question joins, and screens what they return.
- Each source the merge run adds is recorded with its DOI, or its arXiv ID, exactly as the page it read gives it, and named in its report as added.
- `SKILL.md:529`, lit-review item 5: the identifier check runs again, before the patch, on each entry the merge run added too, beside the two kinds it names now (Decision 4).
