## Cases

Each case is an input and its expected result. "Unchanged" means the research-hub script, or `lookup.py` at 0074728, run from a scratch copy before any change.

anchorize_tex.py:

- A1. A `.tex` with three paragraphs separated by blank lines: three blocks, the manifest at `<tex>.block-manifest.json`, the `.tex` byte-identical after the run (`cmp`).
- A2. A `table` environment holding a blank line between two paragraphs: the environment is one block.
- A3. A `.tex` wrapped in `\begin{document} ... \end{document}`: the paragraphs inside are separate blocks, not one.
- A4. The manifest's spans rebuild the file: the blocks and the separators between them, joined, equal the file.

apply_tex_patch.py:

- P1. `replace_block` on one block with the manifest's `old_hash`: exit 0, the output holds the new text, every other block byte-identical, the base byte-identical, `<output>.apply-report.json` written naming the op, its block and its `roadmap_item_ids`.
- P2. An `old_hash` that is not the manifest's: exit 2, no output file written, the base byte-identical.
- P3. A manifest whose `base_sha256` is not the file's (the `.tex` changed after anchorize): exit 2, kind `stale-manifest`, no output written.
- P4. Two ops on one block: exit 2.
- P5. A patch that rewrites a `\section{...}` heading: exit 3 without `--acknowledge-structural`, no output written; with it, exit 0 and the flag in the apply report.
- P6. `--output` equal to the base: exit 2, the base byte-identical.
- P7. `--check-only`: exit 0, no output file and no apply report written.
- P8. On a file of five paragraph blocks with no heading, one patch with an `insert_after` on block 2 and a `delete_block` on block 4 (two of five blocks, under 0.6): exit 0, the new block after block 2 with one blank line between, block 4 gone with its trailing separator, the others byte-identical.
- P9. One patch with two ops, one with the manifest's `old_hash` and one with a stale `old_hash`: exit 2, kind `validation`, no output file, the base byte-identical, so no part of the patch is applied.
- P10. A patch that touches four of five blocks (0.8, above 0.6): exit 3, the flag `block_touched_ratio ... exceeds 0.6`, no output written.
- P11. A `delete_block` of the block holding a `\section{...}`: exit 3, the flag `section count changes from <n> to <m>`, no output written.
