   - Each value is put in NFC first, so a decomposed letter is one character.
   - A letter with a diacritic is its accent command around the base letter: acute `{\'e}`, grave ``{\`e}``, circumflex `{\^e}`, diaeresis `{\"o}`, tilde `{\~n}`, cedilla `{\c{c}}`, caron `{\v{c}}`, ring `{\r{a}}`, macron `{\=a}`, dot above `{\.z}`, breve `{\u{g}}`, ogonek `{\k{a}}`, double acute `{\H{o}}`; on `i` and `j` the dotless forms, `{\'\i}`.
