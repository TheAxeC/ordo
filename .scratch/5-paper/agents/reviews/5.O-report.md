## Judgment calls

- **Batch `resolve`.** OpenAlex is asked alone for every input with an arXiv ID, an arXiv DOI `10.48550/arXiv.<id>` included (ruling 1 names the arXiv ID, and the arXiv DOI meets the same mismatch).
- **Input forms.** A PMID is given as `PMID:<n>`. A title given to `refs` or `cited-by` is a usage error, exit 2. A work OpenAlex lists but its batch reply lacks prints "no record in OpenAlex's reply".
- **The `dblp` line.** It leaves out the authors, writes pages with two hyphens and shows the RDF type name. The cut line stands last in the block.
- **The single strategist's files** are `screening-single.md` and `counts-single.md`.
- **When a start ends its search.**
  - A theme run ends when at least 2 of conditions 1, 2, 3 and 5 hold, or after 4 rounds with none, and reports its loop open or closed.
  - A merge job ends when the work its prompt names is done.
- **The forward job** asks `cited-by --since` the run's year minus 2, which gives the last three years.
- **The stop's answers** are another 8 rounds, or going on with the works named. Under an instruction not to stop recorded at intake, another 8 rounds run once, and then the run goes on with the works named.
- **Revision mode.** Its strategist is a single strategist, so the stop and its figures reach revision mode.
- **Folders and lock files.** Every start runs `lookup.py` with `TMPDIR` set to the run's temporary folder, so the parallel starts share the lock files.
- **The synthesis start** takes its counts from `counts-merge.md`. A key-set line that names a key only "Synthesis Analysis" cites goes to it.
- **The leads jobs and the job `intersections`** start at once, and the first citation round waits for them, since its set holds what they included (ruling 8).

## Host- or user-visible changes

- **`lookup.py resolve` with several DOIs or arXiv IDs.** Before, it took one input only. Now it prints one block per input, opened by `== <input>`, from batch requests of 50 to Crossref, arXiv and OpenAlex's DOIs. OpenAlex is asked alone for an arXiv ID.
- **`lookup.py search`.** Before, it asked Crossref, OpenAlex, Semantic Scholar and arXiv. Now it also asks PubMed.
- **New commands and files.** The new commands are `refs`, `cited-by`, `index-abstract` and `dblp`. `dblp` asks the exact title first, and names a cut at 1000 rows. The new lock and skip files are `ordo-lookup-pubmed`, `ordo-lookup-europepmc` and `ordo-lookup-dblp`, each with its skip file. Replies of `refs`, `cited-by` and `dblp` are now cached too.
- **A `paper` lit-review, full, outline-only or revision search.**
  - Before: the strategist could write scripts, query indexes with `curl` and start agents, and one merge run did all the merge work.
  - Now: every start queries indexes only with `lookup.py`, writes no script, starts no agent, and keeps a screening file and a counts file.
  - The session starts the merge jobs, then the citation rounds over every included source (at most 8), then the merge run, and in lit-review mode the synthesis start, which also takes the outcome of the sources' review.
  - A new stop, "The citation loop does not close", can be reached in full, outline-only, lit-review and revision.
