## Judgment calls

- The batch `resolve` asks OpenAlex for an arXiv ID through its DOI `10.48550/arXiv.<id>` in the `doi:` filter, not `ids.arxiv`, so one OpenAlex request answers DOIs and arXiv IDs together as case N7 requires.
- A PMID is given as `PMID:<n>`. A title given to `refs` or `cited-by` is a usage error, exit 2. A work OpenAlex lists but its batch reply lacks prints "no record in OpenAlex's reply".
- The `dblp` line leaves out the authors, writes pages with two hyphens and shows the RDF type name; DBLP requests wait 90 s, since a SPARQL query took about 14 s live and others time out.
- The single strategist's files are `screening-single.md` and `counts-single.md`.
- A theme run ends its search when at least 2 of conditions 1, 2, 3 and 5 hold, or after 4 rounds with none, and reports its loop open or closed; the session's citation rounds close the loop over the merged set. A merge job ends when the work its prompt names is done.
- The forward job asks `cited-by --since` the run's year minus 2, which gives the last three years.
- The stop's options are another 8 rounds or going on with the works named; under an instruction not to stop recorded at intake, another 8 rounds run once, then the run goes on with the works named.
- Revision mode's strategist is a single strategist, so it runs its own rounds and can reach the stop; revision's stop line and figures show it.
- Every start runs `lookup.py` with `TMPDIR` set to the run's temporary folder, so the parallel starts share the lock files.
- The synthesis start takes each count from `counts-merge.md`, and a key-set line naming a key that only "Synthesis Analysis" cites goes to it.

- `lookup.py search`: before, Crossref, OpenAlex, Semantic Scholar and arXiv; now also PubMed (one more request to E-utilities, "PubMed: ..." lines).

- A `paper` lit-review, full or outline-only run: before, the strategist could write scripts, query indexes with `curl` and start agents, and one merge run did all the merge work; now every start queries indexes only with `lookup.py`, writes no script, starts no agent, keeps a screening file and a counts file, and the session starts the merge jobs, citation rounds up to 8, the merge run and in lit-review the synthesis start. The run folder holds `screening-<name>.md` and `counts-<name>.md` per start. A new stop, "The citation loop does not close", can be reached in full, outline-only, lit-review and revision.

- The brief named `ids.arxiv` for OpenAlex in the batch `resolve`; its own case N7 requires one OpenAlex request for a DOI and an arXiv ID together, which only the `doi:` filter gives (`filter=doi:10.48550/arXiv.<id>`).
- The brief built `dblp` on DBLP's search interface, which answers status 202 with a bot page; ruling A moved it to the SPARQL endpoint.
- The brief's path list leaves out the revision figures. The new stopping rule changes the search-round label drawn in revision mode, and the stop reaches revision's strategist, so `docs/figures/paper/revision.svg` and the two `revision-*.svg` comparison figures change, with their descriptions in `README.md` and `docs/academic-coverage.md`.
