## Judgment calls

- `fetch` by an ID uses the record's DOI when it gives one, else its arXiv ID, else the record's own open-access URL and abstract. The DOI comes first since the DOI path tries every index's open-access URL.
- The printed lines of the ID path: `lookup <index> <id>: found, doi <x>` or `found, arXiv <x>`, `found, no DOI and no arXiv ID[, no open-access URL]`, or the existing "left out" and "not found" lines.
- The fetch rules of the strategist stand in one labelled bullet, "**Reading a candidate.**", under "Screening", with its sub-bullets, since the screening tree, the full-text stage and the annotation rule all point at it.
- The input order for a candidate is DOI, arXiv ID, Semantic Scholar ID, OpenAlex ID, and the key is the same identifier, so no two candidates share a file.
- `writing` Steps 1 now reads one argument and refuses more as "Draft refused", so the Steps numbers 3, 4 and 6 that `paper` SKILL.md:58 and the glossary's Stated in lines cite stay correct.
- `writing` Steps 7: with no opus identifier in the model list, the sentence agent, the first agent Steps 6 names, decides.
- In `gen_comparison.py` the tag of the ruling The second repair of paper is `5.C (<item>)`, such as `[5.C (3)]`, after the form `[4.A R2-6]` the file already uses for a step's ruling.
- The dashed `/writing` box of the detailed comparison figures uses a new style `ruled_maybe` (indigo, dashed), added to `gen_figures.py`'s `STYLES` and `describe`. Its legend row "Dashed indigo box: a ruled agent start that runs only when needed" is drawn only in a figure that has such a box, so the other detailed figures are unchanged.
- ADR 0027 Consequences said "Five cases add starts" and gave the lower-venue answer as one of them; the sentence is removed and the count is now "Four cases". ADR 0024 Consequences now reads "A lit-review run fetches the candidates' texts for screening only, and judges no claim from them." ADR 0025, superseded, is left as it is.
