## Commands that printed the runs

The turns of each session were printed into `b5n/g5-turn1.txt`, `b5n/g5-turn2.txt`, `b5n/ap2-turn1.txt` and `b5n/ap2-turn2.txt` of this session's scratchpad by this read-only `jq` filter, run on each turn's transcript `.jsonl`:

```
F='select((.type=="assistant" or .type=="user") and (.parent_tool_use_id==null)) | (.type) as $t | (.message.content | if type=="string" then [{type:"text",text:.}] else . end)[] | if .type=="text" then "[\($t) text] \(.text)" elif .type=="tool_use" then "[tool_use \(.name)] \(.input|tojson)" elif .type=="tool_result" then "[tool_result] \((.content| if type=="array" then (map(.text? // "")|join(" ")) else tostring end)[0:800])" else empty end'; jq -r "$F" <file>
```

Every agent's final message was printed into `b5n/finals.txt` (1699 lines, 19 agents) by this command, run over both runs' `subagents` folders:

```
for f in $d/*.jsonl; do echo "=== $(basename $f) $(cat ${f%.jsonl}.meta.json)"; jq -r 'select(.type=="assistant" and .message.stop_reason=="end_turn") | .message.content[] | select(.type=="text") | .text' $f; done
```

Single lines of those files were then printed with `sed -n '<n>p'`, `grep -n` and `grep -o`.
