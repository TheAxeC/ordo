## What to build

The rulings are O, P and D45 of `plan.md`'s Rulings.

1. A call of `idea` whose text is a sentence (ruling O). A call of `idea` with more arguments than `idea <project folder> [<sketch file>]` takes is read as the sketch: the whole text after `idea`. No folder is made from it. With no project folder given, the first message asks for one, as it already asks for the sketch when there is none. Write this where the call is read, "What it reads" item 1, and where the sketch is taken, "What it reads" item 17 and "idea" item 3, and add a Stops row for the question for the project folder, in the form of the row "The sketch": when, what it shows, what resumes it. A call of `idea` with no argument at all stays the refusal "No project folder"; a call of one or two arguments is read as today.
2. A call of `full` whose text is a sentence (ruling D45). The same reading for `full`: its text, when longer than `full <project folder> [<sketch file>]` takes, is the sketch it hands to `idea`, and the first message asks for the project folder. Write it in "What it reads" item 1 beside item 1 of this list, and in "full" item 2, which hands `idea` the call's sketch, from a file or from the call's text.
3. The quoted idea of a novelty page made by `idea` (ruling P). In a page that `idea` writes, the section "The idea" quotes only the user's words: the sketch from the progress file, and the user's answers the round's claims rest on. Under each answer that takes an option (a letter or `Agree`), the page states, unquoted, the option it took as the round put it, named by its round and its choice. What the session sums up is never a quoted line. The claims the session drew stay under "## The claims". Write this in `references/novelty_page.md`: the form's line 14 and a rule bullet under the form; and say in "novelty" item 1 or "idea" item 5 of `SKILL.md`, whichever reads more plainly, that a page made by `idea` gives its idea section that way, pointing at the page's form. A page made by `/researcher novelty` keeps the idea as the user gave it, quoted, as today.

Each change is a sentence or a bullet in the style of the lines around it, in the skill's own words. No example in a shipped file is taken from any person's project: an example is made up and says so, as the page's example already does.
