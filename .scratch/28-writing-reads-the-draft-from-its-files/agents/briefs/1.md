## What to build

When the step is done, `/writing` no longer copies the draft or either script's output into any prompt. The session gives each of the four agents file paths, and each agent reads those files itself, whole.

`skills/academic/writing/SKILL.md`, to `docs/dev/skill-layout.md`:

1. **The temporary folder.** After Steps 3 has listed the draft's files, and before Steps 4 runs the scripts, the session makes a temporary folder with `mktemp -d` and holds its absolute path. Put this where the Steps read best: a new item, or the start of Steps 4.
2. **The scripts write into it.** Steps 4 writes the output of `prose_facts.py` to a file in the folder (such as `facts.txt`), and for a `.docx` the output of `docx_paragraphs.py` to another (such as `paragraphs.txt`), each path, the folder's included, quoted as Steps 4 already quotes paths (single quotes, a single quote inside written as `'\''`). A non-zero exit of either script stays the refusal "No facts", with the line the script printed on standard error. Steps 4's "Done when" line says each output is written to its file in the folder, or the refusal is raised.
3. **The prompts give paths.** "Agent prompts" says that each finding agent's prompt holds, in place of the draft's text and the facts:
   - for a `.tex`, `.md` or `.txt` draft: the absolute path of each file of Steps 3's list, in that order, each with its path from the main file's folder, which is the name a finding's place uses;
   - for a `.docx` draft: the absolute path of the paragraphs file in the temporary folder (the agent does not read the `.docx` itself);
   - the absolute path of the facts file;
   - the rule texts and the bullets, as now (unchanged: this step does not change how rules are given).
   The checking agent's prompt holds the same paths, plus every finding of the three reports, the rule texts a finding names and its bullets.
4. **The agents read the files whole.** The bullets of "Finding agent prompt" and of "Checking agent" replace "Work from this prompt alone: ... read no file" with bullets that say three things: read each file the prompt names, whole, before the review, and no other file; a file longer than one read is read in consecutive parts up to its last line; and work from the prompt and those files alone, editing no file, starting no agent, invoking no skill and running no command. Each prohibition stays in a bullet that also names what to do instead (`docs/dev/skill-layout.md`, "Writing for an agent"). The place of a finding in a `.tex`, `.md` or `.txt` draft is still `file:line`, the line number being the file's own line as the read shows it, with the path from the main file's folder that the prompt pairs with the file.
5. **The folder is removed.** The folder is removed with `rm -r '<the folder>'`, quoted as item 2 quotes it and naming only the path `mktemp -d` printed, once the runner reports that the checking agent has ended and before the report and the token line are shown (Steps 7 and 8), since the report is the message that ends the turn and no command runs after it; and on every refusal raised after the folder was made (such as "No facts"). Every agent that reads the folder has ended when it is removed. A refusal raised before it is made has nothing to remove. Steps 7's "Write no file" becomes true of everything outside the temporary folder.
6. **The rest of the page says the same.** The opening paragraph under the title, "What it reads" (the facts and the paragraphs are read from the temporary folder by the agents), Stops (each refusal's "leaves nothing" holds, the folder removed), Anti-patterns (a row for the session pasting the draft or a script's output into a prompt, with why it fails: the session copies the draft four times and the prompts grow with it; do instead: give the paths), the Rules bullet "Every agent gets the whole draft's text" (every agent reads the whole draft from its files, keeping the reason), the Rules bullet "The session passes the outputs of the scripts and the agents' findings on" (the session passes the paths of the outputs), the bullet of "Finding agent prompt" "Take a count from the facts in the prompt" (the facts in the facts file), and every other sentence of the page that names the prompt as the place of the draft or of a script's output, and the `description` only if a sentence in it becomes false. The description stays at most 1,024 characters.
7. **The version.** `metadata.version` goes to "2.3.0" (`docs/dev/skill-layout.md`, "Frontmatter": one part raised once per plan).

## Cases

Each case is checked by reading `skills/academic/writing/SKILL.md`, on the unchanged tree first and after the change.

- A `.tex` main file with one `\input{sections/intro}`: the four prompts hold the absolute paths of the main file and of `sections/intro.tex`, each with its path from the main file's folder, and the facts file's path; no prompt holds a line of either file; each agent is told to read each named file whole. On the unchanged tree: the prompts hold the text as `cat -n` prints it ("Agent prompts").
- A `.docx` draft: the prompts hold the path of the paragraphs file and of the facts file, not the `.docx`; a finding's place is still `paragraph <n>`, with the part in square brackets outside the body.
- A `.md` draft of one file: the prompts hold its one path and the facts file's path.
- A file longer than one read: the agent is told to read it in consecutive parts to its last line.
- `prose_facts.py` exits non-zero: the refusal "No facts" shows the line it printed, and the temporary folder is removed.
- `docx_paragraphs.py` exits non-zero on a `.docx` after the folder is made: the same refusal and the same removal.
- A draft whose path holds a space and a single quote, such as `my draft's/main.tex` (made up): the redirect of each script's output, the paths in the prompts and the `rm -r` each take the path quoted, and `rm -r` names only the folder `mktemp -d` printed.
- The call `/writing a.pdf` (extension refused at "What it reads" 3, raised before Steps 3 lists the files): the refusal is raised before the folder is made, so nothing is removed and nothing is left.
- A run that ends normally: the checking agent ends, the folder is removed, then the report and the token line are shown as the message that ends the turn; no file is left anywhere.
- The checking agent: its prompt holds the same paths as the finding agents' plus the three reports' findings, and it reads the same files whole.

The builder's first task, before any change, is the first run of every case above on the unchanged tree, with each case's result noted.
