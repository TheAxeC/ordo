## Goal

The skill folders grouped under `skills/`: `skills/orchestration/` holds `roadmap`, `grill`, `plan`, `spec`, `refute`, `land`, `plan-orchestration` and `plan-retro`; `skills/ordo/` holds `repo-setup`, `ordo-init`, `ordo-help` and `session-retro`; `skills/code/` holds `code-comments` and `diagnose`; `skills/academic/` holds `paper` and `writing`. `utils/pin.sh`, its test and the README's install routes read the grouped layout, each skill stays installed under its own name, and every path in the tracked files that names a skill folder names its new place. The skills find `plan.yaml` by a search order: the folder named in the call, then `.scratch/`, then `docs/`, then `.agents/`, each of the last three at the repository root, and the first file found is the one used. Every path in a `plan.yaml` is read relative to the folder that holds it; a `plan.yaml` that names no `worktree_root` uses `.agents/worktrees` at the repository root; `land.sh` and `check_config.py` are given the path of the file the skill found and open no other. Ordo's own configuration moves from `.agents/plan.yaml` to `docs/plan.yaml`, each of its paths rewritten relative to `docs/`, and `.gitignore` no longer keeps `.agents/plan.yaml` tracked. The agents a plan starts may run on Claude Fable: the rule in `plan-orchestration` that no agent runs on Fable, and the two comments in the template that say so, are removed. `writing` and `code-comments` start their agents as `paper` starts its roles: on the runner's default agent, the prompt setting no model and no effort, so they follow the session, and `code-comments` reads no `plan.yaml`. When the runner lists no `ordo-<level>` agent for the configured effort, `spec`, `refute`, `plan-orchestration`, `grill` and `diagnose` print a warning that names the missing agent and start the agent the same way, following the session, in place of refusing. `paper`'s format-convert mode runs the pre-submission checks of academic-paper's `references/journal_submission_guide.md` ("Pre-Submission Checklist": the journal selection criteria, the manuscript preparation and the required components) on the manuscript for the venue the run names, and its report gives each check with its result. The guide is copied into `paper`'s `references/` under its own name, changed only where a ruling of yours in the plan's Rulings says so, each with its reason. The row of `docs/academic-coverage.md` for the guide names `paper` and the copied file.
