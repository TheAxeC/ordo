# The user's changes at the selection stop

`SKILL.md`, "first round" item 10, runs this page when the user changes the selection at the stop "The selection". This page is the session's, and no agent is given it.

A change the user makes at the stop "The selection" is made in `selection.md` by the session, and written by the referee where it needs new text.

- The session moves a point between "Selected points" and "Points over the budget", as a whole entry.
- The session moves a point the user takes out, as a whole entry, to a `##` section "Points the user moved out" of `selection.md`.
- Every other change is one entry of the section "Changes to write" of `selected-points.md`, in the session's words: a comment to write as a point with its grade, a comment to join to a point, a point to regrade, or a first-round point to move into or out of the list "First-round points resolved".
- A comment to write is quoted in its entry with its report and its number.
- A left-out new issue the user moves in is quoted whole in its entry, since the referee has not read it.
- After a change, the session writes `selected-points.md` again from `selection.md`, with the section "Changes to write" when there is one.
- When `selected-points.md` holds a minor point in one line or a section "Changes to write", resume the referee with it, as `agents/referee_agent.md`, "The user's changes", says.
- After the referee's rewrite, the rule check of `selected-points.md` reads the file again, as `SKILL.md`, "The rule check", says.
- The session then carries the text back, as `SKILL.md`, "The files of the selection", says.
- The session then removes the section "Changes to write".
- The session then writes `left-out.md` again.
- After each change, the session fills "Count after the cut" again.
- A change that needs no new text resumes neither the referee nor the rule check.
