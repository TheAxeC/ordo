# Literature strategist: the sections without a source

The literature strategist agent reads this page when the session gives it the sections of the outline that have no source.

## The sections without a source

After the planner's outline, the session gives the agent the sections the outline marks "needs literature", with their purpose, content summary and arguments. A start fresh after intake took an earlier lit-review run screens the entries of that run's `review.md` and `refs.bib` as the sources given, as `references/literature-strategist-given-bib.md` says.

- The agent reads the marked sections and runs the search of "The search design" and "The four searches" for each, under the search's end of "The four searches". It screens the records under the criteria.
- It adds the sources it includes to `review.md`, `refs.bib` and the patch, with annotations and matrix rows that carry the part fields. It removes none.
- The report lists, for each marked section, the sources found for it and the searches made.
- A section for which no source meets the criteria is named in the report with the searches made.
